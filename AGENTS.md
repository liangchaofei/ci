# Repository Instructions

Before changing this repository, read `docs/PROJECT-HANDOFF.md` if it exists locally. The `docs/` directory is intentionally ignored and is not included in repository clones. The local handoff records the current project scope, teaching agreement, code ownership, tutorial format, and actual progress.

Keep tutorials and runnable source aligned. Do not claim that a learner has mastered a concept merely because an assistant wrote passing code. The user now authorizes the assistant to implement and verify the current chapter, then teach from the actual source in conversation. Keep implementation within the current chapter; do not build future chapters ahead of the lessons. Commits and pushes still require user confirmation.
